# User Requirements

Build a website for MetricStack, a SaaS company. MetricStack provides a real-time analytics dashboard that helps SaaS companies track MRR, churn, LTV, and other key metrics in one place. Include a hero section with a dashboard preview. Include feature breakdowns for cohort analysis, revenue forecasting, and custom reports. Include an integrations section for Stripe, Paddle, and Chargebee. Include pricing plans. Include a signup form. Assume all unanswered details and create a polished SaaS website direction. Design variation: clean product-led modern SaaS layout with strong dashboard visuals, crisp typography, and a conversion-focused homepage.
